# 友田翼 技術士・中小企業診断士事務所

GitHub Pagesで公開できる、ビルド不要の静的サイトです。

## 構成

- `index.html`：案内、プロフィール、経歴、文献・特許、Googleフォーム
- `styles.css`：PC・スマートフォン向けのレイアウトと配色
- `app.js`：課題別切り替え、事例絞り込み、事例詳細、メニュー、フォーム展開
- `favicon.svg`：サイトアイコン

## ローカル表示

プロジェクトのフォルダで `python3 -m http.server 8000` を実行し、表示されたローカルURLを開きます。

## GitHub Pagesでの公開

リポジトリの Settings → Pages で **Deploy from a branch** を選択し、公開用ブランチの **/(root)** を指定します。ビルドや外部サービスのキーは不要です。

## 更新する場所

事例本文・絞り込み対象は `app.js` の `cases`、課題別の支援内容は `solutions` を編集します。経歴・資格・文献は `index.html` にあります。

問い合わせは既存のGoogleフォームを使います。受け付けや通知の設定は、フォームの管理画面で確認してください。回答データはこのリポジトリには保存されません。

社名、事例の実施年、非公開の連絡先、未確認の料金・数値成果は掲載していません。
